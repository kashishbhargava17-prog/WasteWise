# WasteWise

A functional Design Thinking prototype for Case Study 5: Improving Household Waste Segregation.

## Features
- Working navigation and buttons
- Waste category search
- Quick-search examples
- Waste category guide
- 10-question interactive quiz
- Quiz score and best score
- Local progress tracking with localStorage
- Responsive mobile layout
- No backend or paid services required

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload `index.html`, `styles.css`, and `app.js` to a GitHub repository. Enable GitHub Pages from the repository's Pages settings.

## Important
This is an educational prototype. Waste categories and actual disposal procedures can vary by location, so users should follow their local waste-management authority's instructions.
